# 0xBlu3Guy

The source of my blog: [0xblu3guy.github.io/blog](https://0xblu3guy.github.io/blog/)

Posts are Markdown files in `src/content/posts/`, built into a static site with
[Astro](https://astro.build) and published to GitHub Pages on every push.

```bash
npm install
npm run dev     # preview at http://localhost:4321/blog/
npm run build   # what GitHub runs
```
